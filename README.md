# 📱 QR Code Component

This is my solution to the **Frontend Mentor - QR code component** challenge.

## 🧾 Overview

A simple, clean, and responsive card UI component that displays a QR code with a title and description. Built using only HTML and CSS.

## ✨ Features

- ✅ Fully responsive layout
- 🖼️ Custom image placement with alt text
- 🧼 Minimal and modern design
- 📐 Utility-based spacing & sizing
